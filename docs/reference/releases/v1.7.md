# v1.7

- **Release date**: March 24, 2026
- **GitHub release**: [v1.7.0](https://github.com/ellanetworks/core/releases/tag/v1.7.0)

## New features

- **Radio details page**: Click on a radio and view radio connection information, connected subscribers and recent network events. Added cross-links between radios and subscribers. Useful for provisioning, troubleshooting, and audit.

## Maintenance

- **Increased Samsung phone support**: Set the `IMS-VoPS` for compatibility with some Samsung phones (ex. Galaxy A53, A56) and likely other models.
- **Build speed up**~90% UI build time speedup from upgrading Vite 7 to 8 and removing typescript checks from the build stage.
- **Security fixes**: Many security improvements at the API, Radio, and subscriber layers.
- **Improved observability**:
    - Use canonical fields for consistent log messages.
    - Record error and status in oTLP spans.
- Dependency updates
- Bug fixes

## Documentation

- **[Native XDP veth How-to guide](../../how_to/native_xdp_veth.md)**: When Ella Core's N3 or N6 interface is a veth pair and XDP is set to native mode, you must attach a minimal XDP program to the peer side of the veth.
